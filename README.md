# story-factory

Конвейер для англоязычного YouTube-канала аудиоисторий. Главная инструкция — [CLAUDE.md](CLAUDE.md).

Как пользоваться (в Claude Code, в этой папке):
- `/new-episode` — сделать новый эпизод от идеи до пакета для загрузки;
- `/research-competitors` — свежая разведка по конкурентам;
- `/generate-ideas` — новые идеи;
- `/weekly-review` — недельный отчёт по статистике канала.

Первый запуск на новой машине: `bash tools/setup.sh`.
