# Фабрика историй — англоязычный YouTube-канал длинных аудиорассказов

Этот репозиторий — конвейер, который делает 60–100-минутные аудиоистории на английском для американской аудитории 55+.
Claude выполняет почти все шаги сам; человек (владелец канала) участвует в трёх точках: выбирает идею, генерирует обложку в Google Flow, проверяет и загружает видео.

## Канал
- **Ниша:** рассказ от первого лица: американка 60–72 лет; её предаёт семья (сын, невестка, муж, падчерица, сестра), она спокойно и умно восстанавливает справедливость и начинает новую жизнь.
- **Аудитория:** женщины и мужчины 55–75 из США, слушают фоном. Подробно — `channel/audience.md`.
- **Голос:** утверждён, менять нельзя без согласия владельца — `channel/voice.md`.
- **Формула истории:** `channel/story-formula.md`. **Стиль текста:** `channel/style-guide.md`. **Названия и обложки:** `channel/titles-and-covers.md`.

## Конвейер (скиллы в `.claude/skills/`)
| Шаг | Скилл | Результат |
|---|---|---|
| 1. Разведка | `research-competitors` | `research/outliers-ДАТА.md`, обновлённый `research/patterns.md` |
| 2. Идеи | `generate-ideas` | новые идеи в `ideas/backlog.md`; **владелец выбирает одну** |
| 3. Сценарий | `write-episode` (агент `writer`) | `episodes/EXXX-slug/` : паспорт, план, главы |
| 4. Редактура | `edit-episode` (агент `editor`) | `review.md`, исправленные главы |
| 5. Озвучка | `narrate-episode` | `audio/episode.mp3`, таймкоды глав, `qc.md` |
| 6. Обложка | `make-cover` | промпт для Flow → **владелец генерирует** → 3 варианта обложки |
| 7. Видео | `render-video` | `video/episode.mp4` |
| 8. Пакет загрузки | `publish-pack` | `publish.md`: название, описание, теги, главы, чек-лист; **владелец загружает** |
| 9. Статистика | `weekly-review` | `analytics/weekly/ДАТА.md`, обновлённый `analytics/learnings.md` |

Весь цикл одного эпизода запускает скилл `new-episode` — он ведёт по шагам и останавливается в точках, где нужен человек.

## Жёсткие правила
1. **Только вымысел.** Никогда не называть историю «true story», «real story», «based on real events». В описании — дисклеймер о вымысле. Никаких реальных людей, компаний-обидчиков, узнаваемых частных лиц.
2. **Не копировать конкурентов.** Их видео — только источник паттернов (какие конфликты и развязки цепляют). Сюжеты, сцены, имена, фразы — свои.
3. **Каждый эпизод уникален.** Перед написанием сверять идею с `episodes/*/idea.md`: другой злодей, другая сцена унижения, другой механизм расплаты. Это защита от правила YouTube о шаблонном массовом контенте.
4. **Голоса реальных людей не клонировать** без их письменного согласия. Чужие голоса из сервисов (ElevenLabs, Higgsfield и т.п.) не копировать.
5. **Без** натуралистичного насилия, секса, мата, ненависти к группам людей. Злодей — конкретный человек, не «все невестки».
6. **Раскрытие ИИ:** при загрузке ставить отметку YouTube «Altered or synthetic content» (обложки фотореалистичные, голос синтетический).
7. Ничего не публиковать и не загружать от имени владельца без его подтверждения.

## Структура
```
channel/     правила канала: голос, аудитория, формула, стиль, названия и обложки
research/    конкуренты (competitors.txt), разведка, паттерны
ideas/       backlog.md — банк идей с оценками
episodes/    по папке на эпизод (см. episodes/README.md)
analytics/   learnings.md — что работает; weekly/ — отчёты
tools/       скрипты: озвучка, проверка, обложки, видео, разведка
```

## Окружение
- Первый запуск на новой машине: `bash tools/setup.sh` (ставит Python-окружение `.venv`, модель голоса в `models/`, шрифт).
- Python-скрипты запускать через `.venv/bin/python`.
- Для загрузок с Hugging Face нужна переменная `HF_HUB_DISABLE_XET=1` (setup.sh и скрипты ставят её сами).
- Тяжёлые файлы (аудио, видео, модели) в git не попадают — см. `.gitignore`.
