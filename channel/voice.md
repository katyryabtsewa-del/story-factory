# Голос канала (утверждён)

Эталон: `B_room.mp3`. Американка за 50, тёплый спокойный голос, читает цельно, без рваных пауз.

## Рецепт
- Модель: Kokoro v1.0 (файлы в `models/kokoro/`, ставит `tools/setup.sh`) (открытая, лицензия Apache 2.0, коммерческое использование разрешено), библиотека `kokoro-onnx`.
- Смесь голосов: `af_sarah` 50% + `af_nicole` 50%.
- Скорость: 0.9.
- Текст читается целыми блоками по ~1500 символов из целых абзацев. **Никогда не резать на отдельные предложения и не вставлять паузы вручную**: интонация рвётся и звучит как ИИ.
- Обработка (`tools/master.sh`): тон ниже на ~1,5 полутона (голос старше), теплее на низах, мягче на верхах, лёгкое сжатие, отражения маленькой комнаты, едва слышный фон комнаты, громкость −16 LUFS.

## Установка с нуля
```bash
bash tools/setup.sh
```

## Запуск
```bash
.venv/bin/python tools/narrate.py OUT.wav script/ch01.txt script/ch02.txt ...
tools/master.sh OUT.wav audio/episode.mp3
```

## Проверка
После озвучки прогонять аудио обратно в текст (faster-whisper) и сверять со сценарием.
