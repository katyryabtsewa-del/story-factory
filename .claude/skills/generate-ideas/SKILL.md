# Новые идеи

Прочитай: `research/patterns.md` (свежий раздел), `analytics/learnings.md`, `ideas/backlog.md`, все `episodes/*/idea.md`, `channel/story-formula.md`, `channel/titles-and-covers.md`.

1. Придумай 12 идей. Каждая: название по формуле (≤100 символов), злодей, сцена унижения, событие-обстановка, механизм расплаты из банка в `story-formula.md`, логлайн в одно предложение. Длина по умолчанию 60 минут; идеи с сильным материалом на две серии или 95 минут — помечать.
2. Отбрось идеи, которые повторяют уже вышедшие или выбранные по паре «злодей + механизм расплаты».
3. Оцени каждую по 4 критериям 1–5 (крючок · новизна для нас · сила расплаты · понятность) с учётом `learnings.md`.
4. Допиши в таблицу `ideas/backlog.md` со статусом 💡. Покажи владельцу топ-5.
